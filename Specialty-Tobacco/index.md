[← Back to Main Repository Landing Page](../)

## Dataset Overview
This directory contains data and documentation tracking specialty tobacco retail locations and visitor patterns across the United States. 

* **Associated Publication:** Patterns of Specialty Tobacco Retail Locations and Visitor Counts in the United States (*Tobacco Control*, 2026).
* **DOI Link:** [10.1136/tc-2026-060085](https://doi.org/10.1136/tc-2026-060085)
* **PubMed:** [PMID: 42425894](https://pubmed.ncbi.nlm.nih.gov/42425894/)
