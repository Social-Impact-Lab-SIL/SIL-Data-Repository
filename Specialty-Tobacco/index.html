Specialty Tobacco Retail Locations and Visitor Counts

Overview

When using any of this project's data, please reference the correct peer-reviewed publication listed below. Please see the publication for additional details on how the measures are constructed. Where multiple versions of the data exist, we recommend using the most recent version for new projects.

  • Associated Publication: Patterns of Specialty Tobacco Retail Locations and Visitor Counts in the United States (Tobacco Control, 2026).
  • DOI Link: 10.1136/tc-2026-060085
  • PubMed: PMID: 42425894
  • Data: Advan Research. (2022). Foot Traffic / Monthly Patterns [Dataset]. Dewey Data. https://doi.org/10.82551/BEB1-2831

Data Download

You can download the processed dataset for this study below. Match rates and visitor counts are restricted to only the top decile by population:

Download StateCountyData2024.xlsx (Excel Workbook)

Data Description

The downloadable file contains two data tabs (State and County level) containing Google store counts independently queried using a third-party program, match rates between Google and Advan stores, and visit counts from Advan:

  • State-level cross section, May 2024
  • County-level cross section, May 2024
