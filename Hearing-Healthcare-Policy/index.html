Hearing Healthcare Policy Data

When using any of this project's data, please reference the correct peer-reviewed publication listed below. Please see the publication for methodological details. Where multiple versions of the data exist, we recommend using the most recent version for new projects.

1. Private Insurance Hearing Aid Mandates

Private insurance hearing aid mandates have been adopted by an increasing number of states and vary in age eligibility and generosity. This project describes the details of private insurance hearing aid mandates for each state over time.

Download hear_priv_V2.xlsx (Excel Workbook)

Associated Publication:

Arnold, M. L., Heslin, B. J., Dowdy, M., Kershner, S. P., Phillips, S., Lipton, B., & Pesko, M. F. (2024). Longitudinal Policy Surveillance of Private Insurance Hearing Aid Mandates in the United States: 1997-2022. American Journal of Public Health, 114(4), 407–414. https://doi.org/10.2105/AJPH.2023.307551 | PubMed

Data Description: The downloadable Excel file contains:

  • “Private Insurance Hearing Aid Coverage Mandates Effective Dates and Details, as of January 1, 2023: United States”
  • “Status of Private Insurance Hearing Aid Coverage Mandates, by State and Month”

2. Key Policy Features of State Medicaid Hearing Aid Coverage for Adults, 2023

This dataset tracks cross-sectional parameters of state Medicaid hearing aid coverage provisions for adults.

Download hear_mcaidcross_V2.xlsx (Excel Workbook)

Associated Publication:

Arnold, M. L., Tonti, L., Phillips, S., Kershner, S. P., Lipton, B. J., Heslin, B., Ukert, B. D., & Pesko, M. F. (2025). Number Of States Providing Medicaid Hearing Aid Coverage For Adults Increased; Variability Was Substantive, 2017-23. Health Affairs, 44(12), 1522–1529. https://doi.org/10.1377/hlthaff.2025.00270 | PubMed

Data Description: The downloadable Excel file contains: “Key Policy Features of State Medicaid Hearing Aid Coverage for Adults, 2023”

3. Longitudinal Trends in Medicaid Hearing Aid Coverage for Adults in the United States: 2003-2023

This longitudinal dataset provides monthly tracking of state Medicaid hearing aid coverage determinations.

Download hear_mcaidlong_V1.xlsx (Excel Workbook)

Associated Publication:

Arnold, M., Tonti, L., Phillips, S., Kershner, S., Lipton, B., Heslin, B., Ukert, B., Hebert, R., & Pesko, M. F. (2026). Longitudinal Trends in Medicaid Hearing Aid Coverage for Adults in the United States: 2003-2023. American Journal of Audiology. https://doi.org/10.1044/2026_AJA-25-00204 | PubMed

Data Description: This Excel workbook contains the following sheets:

  • Data View: Status of Medicaid Hearing Aid Coverage, by State and Month
  • State View: Coverage Determination from 01/2003 to 12/2023

4. Hearing Health Care Professional Workforce

This dataset provides state-level counts and supply-demand metrics mapping the hearing healthcare professional workforce.

Download hear_prof_V1.xlsx (Excel Workbook)

Associated Publication:

Garuccio, J., Ukert, B., Arnold, M., Phillips, S., & Pesko, M. F. (2025). Using supply and demand to identify shortages in the hearing health care professional workforce. JAMA Otolaryngology–Head & Neck Surgery. Published online July 31, 2025. https://doi.org/10.1001/jamaoto.2025.2112 | PubMed

Data Description: This Excel workbook contains the following sheets:

  • State-level Counts of Audiologists
  • State Count of Hearing Instrument Specialists
  • State Count of Audiologists and Hearing Instrument Specialists
