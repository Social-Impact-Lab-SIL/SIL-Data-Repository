Hearing Healthcare Policy Data

This repository hosts longitudinal policy surveillance data tracking state-level regulations, insurance mandates, Medicaid coverage, and workforce distributions for hearing healthcare in the United States by state and time. Please see the publications below for additional details on how the measures are constructed. Where multiple versions of the data exist, we recommend using the most recent version for new projects.

1. Private Insurance Mandates

Private insurance mandates for hearing aids vary across states and time, making longitudinal and cross-sectional comparisons challenging.

Version 2

Download Private Insurance Mandates Data Version 2 (Excel Workbook)

Data Description:

  • Details effective dates, age eligibility rules, and generosity criteria for private insurance hearing aid mandates by state over time.
  • Provides standardized variables for empirical policy evaluation.

2. State Medicaid Coverage (Cross-Section)

This dataset tracks cross-sectional parameters of state Medicaid hearing aid coverage provisions for adults.

Download State Medicaid Coverage Cross-Section Data Version 2 (Excel Workbook)

Data Description:

  • Details key policy features and cross-sectional parameters of state Medicaid hearing aid coverage provisions for adults.
  • Captures multi-state differences in benefit caps, prior authorization rules, and device replacement frequencies.

3. State Medicaid Coverage (Longitudinal)

This longitudinal dataset provides monthly tracking of state Medicaid hearing aid coverage determinations.

Download State Medicaid Coverage Longitudinal Data Version 1 (Excel Workbook)

Data Description:

  • Tracks monthly longitudinal changes in state Medicaid hearing aid coverage policies.
  • Spans from 2003 through recent surveillance periods to support robust quasi-experimental designs.

4. Hearing Health Professional Workforce

This dataset provides state-level counts and supply-demand metrics mapping the hearing healthcare professional workforce.

Download Hearing Health Professional Workforce Data Version 1 (Excel Workbook)

Data Description:

  • Reports state-level counts and supply metrics for audiologists and hearing instrument specialists.
  • Allows researchers to evaluate provider density alongside insurance policy changes.
